## About
This playground provides examples of using Sphinx for documentation, focusing on two basic repository layouts: keeping your project and its Sphinx files together in one repository or splitting them across two repositories.

## What's here?
You'll find these three example repositories to explore:
* [sphinx-single](https://github.com/sphinx-playground/sphinx-single): a single repository containing both the project and Sphinx
* [sphinx-split-project](https://github.com/sphinx-playground/sphinx-split-project): the project repository in a split-repository layout
* [sphinx-split-sphinx](https://github.com/sphinx-playground/sphinx-split-sphinx): the Sphinx repository in a split-repository layout
  
Download or clone the examples, explore their contents, change things, and experiment to your heart's content.

## Need help?
* Want some guidance? Visit my [Sphinx TIL](https://github.com/Elliria/sphinx-til) collection, where you'll find explanations, examples, and instructions to help you get started.
* Need additional help using the examples or exploring an automated solution for your project? Start a discussion in any of the repositories.
