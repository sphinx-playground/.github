# Welcome to the Sphinx Playground!
This playground provides examples of using Sphinx for documentation, focusing on two basic repository layouts: keeping your project and its Sphinx files together in one repository or splitting them across two repositories.

## What's here?
You'll find these three example repositories to explore:
* [sphinx-duo-code](https://github.com/sphinx-playground/sphinx-duo-code): the project repository in a split-repository layout
* [sphinx-duo-docs](https://github.com/sphinx-playground/sphinx-duo-docs): the Sphinx repository in a split-repository layout
* [sphinx-mono](https://github.com/sphinx-playground/sphinx-mono): a single repository containing both the project and Sphinx
  
Download or clone the examples, explore their contents, change things, and experiment to your heart's content.

## Need help?
* Want some guidance? Visit the [Sphinx section in my TIL collection](https://github.com/Elliria/til#sphinx), where you'll find explanations, examples, and instructions to help you get started.
* Need additional help using the examples or exploring an automated solution for your project? Start a discussion in any of the repositories.
