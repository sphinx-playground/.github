# About Sphinx Playground
This playground provides examples of using Sphinx for documentation, focusing on two basic repository layouts: keeping your content and its Sphinx files together in one repository or splitting them across two repositories.

## What's here?
You'll find these three example repositories to explore:
* [sphinx-single](https://github.com/sphinx-playground/sphinx-single): a single repository containing both the project and Sphinx
* [sphinx-split-guest](https://github.com/sphinx-playground/sphinx-split-guest): a repository for the content in a split-repository layout
* [sphinx-split-host](https://github.com/sphinx-playground/sphinx-split-host): a repository for Sphinx in a split-repository layout
  
Download or clone the examples, explore their contents, change things, and experiment to your heart's content.

## Need help?
* Want some guidance? Visit the [Sphinx TIL](https://github.com/Elliria/sphinx-til) collection, where you'll find explanations, examples, and instructions to help you get started.
* Need additional help using the examples or exploring an automated solution for your project? Start a discussion in any of the repositories.

## Important
> **Work in progress:** This organization is being prepared for the initial release of each of the repositories. Its contents and configuration are likely to change until the first version is tagged.
>
> The example repositories in this organization are intended to remain as simple as possible and to remain reliably the same once a release is tagged. However, action and Python versions will occasionally be updated using the [Maintenance](https://github.com/sphinx-playground/.github/blob/master/MAINTENANCE.md) guide in this organization's repository. Other possible environmental changes may sometimes also make updates necessary.
>
> Once a repository has an initial tagged release, subsequent updates will also be tagged so that you can choose known versions to work with. The TILs in the [Sphinx TIL](https://github.com/Elliria/sphinx-til) collection will also contain tag numbers.
